# Citation

Recommended repository citation:

> TULIP Lab. *TULIP Lab Open Data Repository*. https://github.com/tulip-lab/open-data. Licensed under CC BY 4.0.

If you use a specific dataset, also cite the associated paper or dataset-level citation listed in that dataset's README.

No repository-level DOI is currently recorded in this repository. A repository-level DOI may be added later as an optional future enhancement. Dataset-level DOI information, where available, is documented in the dataset README files and summarized in [DATA-SOURCES.md](DATA-SOURCES.md).
